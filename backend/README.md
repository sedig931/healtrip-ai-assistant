# chat Project for HealTrip

A simple prototype for AI chat

Tech Uses : 
- Next.js
- React
- TypeScript
- Node.js
- Express
- Mock Database

How it works : 

The user sends a message from the chat interface
The frontend sends the message and conversation history to the backend
The backend passes the request to the Agent

The Agent can :
- Ask clarification questions
- Decide the next step
- Search for doctors
- Search for hospitals
- Handle second opinion requests

Architecture : 
Next.js -> Express API -> Agent -> Tools -> Mock Data

Tools
searchDoctors()
Searches available doctors by specialty and city

searchHospitals()
Searches hospitals by city

The Agent does not create doctor or hospital information, It uses the data returned by the tools

Mock Database
The prototype uses simple static data containing:
- Doctors
- Hospitals
- Specialties
- Cities
- Availability

This can later be replaced with real dataBase without changing the main architecture

for Example : 
User Send : "I have chest pain"
The Agent asks a clarification question : 
If the user confirms severe symptoms => the Agent searches the hospital data for emergency options
If the user asks for a cardiologist => the Agent uses searchDoctors()
If the user asks for a second opinion => the Agent suggests seeking another doctor in the same specialty

Languages :

The interface supports Arabic and English and the selected language is sent to the backend

Security and Error Handling :
The backend validates the message and limits message size and conversation history and handles invalid requests and server errors
All doctors and hospital data is kept on the backend and is not generated by the Agent

Notes :
This is only a prototype The doctor and hospital data are fictional mock data
The current Agent uses simple decision logic instead of an external LLM
The architecture can later be connected to an LLM provider and a real database

How to run ? 

Frontend => npm install => npm run dev =>  http://localhost:3000

Backend => cd backend => npm install => npm run dev => http://localhost:5000
